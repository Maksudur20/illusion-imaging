# Illusion Imaging — Corporate Website

A modern, responsive, and luxury-crafted 3-page corporate frontend website for **Illusion Imaging**, specializing in:
1. **Solar Energy System Sales & Services**
2. **Medical Equipment Import, Supply & Service**

---

## 🌟 Key Highlights

- **Aesthetics & Typography**: Royal luxury branding with **Cinzel** (classical serif) and high-legibility **Plus Jakarta Sans** & **Inter**.
- **Tech Stack**: Pure **HTML5**, **Vanilla CSS3**, and **Vanilla JavaScript** (Zero build steps, 100% frontend-only).
- **Core Pages**:
  - `index.html` — Corporate Home with dual-division showcase, trust credentials, and featured products.
  - `about-services.html` — Detailed corporate background, solar engineering services, and medical supply workflows.
  - `products-contact.html` — Interactive product catalogue with live category filtering, modal popups, custom select dropdown, and quotation inquiry form.
- **Interactive UI Components**:
  - Inset sleek scrollbars for modal dialogues.
  - Custom luxury select dropdown with division icons and gold checkmarks.
  - Interactive specification modal for solar & medical hardware.
  - Mobile responsive drawer navigation.
  - Frontend form validation with animated toast notifications.

## 🚀 How to Run Locally

Simply double-click `index.html` or run a local static server:

```bash
# Using Node / npx
npx serve -l 8080

# Or using Python (if available)
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.
